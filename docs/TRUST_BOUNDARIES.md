# Trust Boundaries

PeakLogic validates and organizes evidence. It does not certify workmanship or safety.

## Never infer from ordinary media alone
- structural capacity
- fastener torque/embedment
- hidden moisture
- weld/bond strength
- code/regulatory compliance
- manufacturer compliance
- warranty approval
- safe-for-use certification

## Human-owned states
- professional approval/rejection
- safety-sensitive conclusions
- exception disposition after missed proof
- final customer-facing claims

## Quality-critical flag
A workflow/documentation flag that activates an approved proof template. It is not an autonomous safety determination.

## Failure rule
If proof was not captured before concealment, create an exception and escalate. Never synthesize or backfill evidence.
