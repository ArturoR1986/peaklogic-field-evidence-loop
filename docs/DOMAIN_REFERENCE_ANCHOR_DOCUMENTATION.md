# Domain Reference — Fall-Protection Anchor Documentation

## Purpose
Ground the competition use case without turning PeakLogic into an installation authority.

PeakLogic's proof-point template is a **documentation workflow**, not a manufacturer installation manual.

## Why this workflow is credible
German DGUV guidance on permanent anchorage devices explains that installation documentation is important for later inspection because the attachment can become concealed or inaccessible. DGUV material also calls for photographic documentation when attachment details may no longer be visible later.

Official references:
- DGUV Information: Schutzmaßnahmen gegen Absturz auf Dächern  
  https://publikationen.dguv.de/regelwerk/dguv-informationen/2952/schutzmassnahmen-gegen-absturz-auf-daechern-planungsgrundlagen-zur-auswahl-von-absturzschutzsystemen
- DGUV FBPSA-017: Anschlageinrichtungen und -möglichkeiten für PSA gegen Absturz  
  https://publikationen.dguv.de/regelwerk/publikationen-nach-fachbereich/persoenliche-schutzausru-stungen/persoenliche-schutzausruestung-gegen-absturzrettungsausruestungen/5005/fbpsa-017-anschlageinrichtungen-und-moeglichkeiten-fuer-psa-gegen-absturz

## Product-specific rules remain product-specific
Manufacturer instructions can specify substrate, fastening, drilling, anchoring, geometry, and other requirements.

One official product example from INNOTECH:
- POINT-15  
  https://www.innotech-safety.com/de-de/absturzsicherungen/produkte/produktfinder/detail/produkt/point-15

The product page lists concrete substrate requirements, bore-hole dimensions, and a specified anchoring system. This illustrates why PeakLogic must not invent installation requirements from pixels or a generic work order.

## System boundary
PeakLogic may:
- identify which approved proof-point template applies,
- remind the crew to capture required evidence before concealment,
- check whether media is usable/redundant/likely relevant,
- organize evidence for professional review,
- expose missing or uncertain proof.

PeakLogic must not independently conclude:
- structural capacity,
- anchoring strength,
- embedment/torque not visibly measured,
- product/manufacturer compliance,
- regulatory compliance,
- safe-for-use status.

## Production rule
Before using a proof template on a real product, the template must be reviewed against the exact current manufacturer instructions and applicable site/company process.
