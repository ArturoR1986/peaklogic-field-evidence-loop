1. Job Progress State must be spatially hierarchical, not "roof = in progress".


Working structure:
Job
├── Main upper roof
│   ├── insulation
│   ├── membrane
│   ├── seams
│   └── drains
├── Secondary / lower roof zones
├── Perimeters by side/zone
│   ├── roof-side restraint
│   ├── upstand
│   ├── exterior edge
│   └── corners
├── Chimney / penetrations
├── Drainage
├── Materials
├── Site readiness
└── Blockers / exceptions


2. Pre-arrival readiness is part of the product.
PeakLogic should compare the next planned work package against fresh site evidence before crew mobilization.


Major readiness items:
- access
- scaffold / temporary works
- lifting
- material availability
- work-zone obstruction
- prerequisite trades


3. Exact product identity should be documentary-first.
Use:
work order / drawings
→ Lieferschein / shipping manifest
→ packaging / OCR
→ field appearance.


4. Seam quality should not be reduced to one visual "good/bad" classification.
Use a seam evidence stack:
- system identity
- overlap geometry
- preparation evidence
- trial weld / peel test
- welding process
- seam geometry
- mechanical seam check after cooling
- visible defect scan
- human acceptance
