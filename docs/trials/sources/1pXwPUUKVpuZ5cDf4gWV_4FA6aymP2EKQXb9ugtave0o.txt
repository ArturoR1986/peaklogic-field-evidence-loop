IMPORTANT WORK-ORDER INSTRUCTIONS THAT AFFECT EVIDENCE


The visible work-order instructions include:


1. Slope / planning references
- tapered-insulation plans, floor plans, visualizations and details are part of the job orientation.
- supporting RYGOL documents specify tapered-insulation layouts and state that tapered boards are to be installed in offset/staggered arrangement.


2. Drain / overflow work
- roof drains are to be recessed to the stated flange level.
- emergency overflows are specifically referenced.
- emergency overflows are to be cut / trimmed as described.
- drain / overflow interfaces and surrounding sealing details are called out.


3. Wall / interface details
- wall connection is to follow the attached detail.
- various connection / sealing materials are listed.


4. Seam / process control
- seam inspection / seam control is explicitly listed.


5. Component confirmation
- the crew is instructed to check whether all required component parts are present and then report back to the site manager.


6. PV / conduit / opening checks
The work order explicitly asks questions/checks including:
- whether PV penetrations are made,
- whether conduits are long enough,
- whether emergency-overflow cut-outs fit.


7. Anchorage-point documentation
The highlighted instruction states:
- anchorage points are to be sealed with Alutrix, not Eurasol.
- documentation of the ASP / anchorage point must show the arrow in the photograph so the embedment depth is recognizable.


This is a critical evidence-before-concealment requirement.


8. Photo evidence before departure
The highlighted instruction states that:
- before departure and before the site is cleared, photos must be sent to the site manager,
- without photos as proof, WeberHaus may not be invoiced,
- if the responsible worker forgets, the instruction warns that the person may have to return to the site to complete the documentation.


This strongly supports the PeakLogic use case:
the job already requires evidence; the operational pain is making sure the right evidence is captured, linked to the work order, and ready for office review before it is too late.
