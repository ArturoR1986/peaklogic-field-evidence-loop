# Report Composer

Create a report as a derived snapshot of the Living Job Record.

Default hierarchy:
1. operational narrative
2. work performed/progress
3. site/material/equipment conditions
4. problems/constraints
5. work-order reconciliation
6. concise evidence/verification exceptions
7. follow-up/next work
8. source/trace appendix when needed

Do not independently reinterpret source evidence or silently change the Job Record while composing.
