# Product-specific contribution rules

Build only the authorized Field Evidence Loop increment. Start with `README.md`,
`START_HERE.md`, and `docs/review/STATUS.md` for current behavior and its limits.

- Preserve the source requirement → bound media → OpenCV result → state/action → trace chain.
- Keep OpenCV 5 substantive and verify its runtime without overrides.
- Do not invent manufacturer rules, component bindings, semantic predictions or acceptance.
- Keep physical progress, evidence completeness and professional review separate.
- Preserve failed/inconclusive results and missing-proof history.
- Keep original field media private; do not commit credentials, local databases or unrelated projects.
- Run the existing tests and reviewer verification before claiming a change is ready.
- Historical build packets in `docs/development/history/` are context, not new assignments.
- Do not merge or change repository access without explicit owner approval.

This file covers this product repository only; it is not a broader agent-system contract.
